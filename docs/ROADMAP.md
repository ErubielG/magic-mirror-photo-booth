# Engineering roadmap

1. Test published source changes on a backup Raspberry Pi image.
2. Move camera initialization into a recoverable/degraded startup mode.
3. Make print queue, pickup numbers and session logs durable.
4. Add capture, print-request, print-confirmation and error counters with timestamps.
5. Separate mirror ownership from browsing/printing actions.
6. Strengthen session authorization, CSRF resistance and photo retention controls.
7. Recover event statistics without duplicating original/print-sheet files.
8. Publish reproducible installation and hardware-in-the-loop test coverage.

These are planned improvements, not features claimed complete.
