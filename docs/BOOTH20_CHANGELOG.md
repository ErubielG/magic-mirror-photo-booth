# Selected changes in version 20

- Sequential bilingual instructions displayed prominently on the mirror.
- Three-step phone onboarding.
- Reminders to disconnect from PhotoBooth Wi-Fi after finishing, reducing guest association pressure on the local AP.
- Up to 300 in-memory print queue items displayed instead of 40.
- QR codes remain hidden while the mirror is in use.

Earlier versions introduced an anti-stall capture watchdog, iPhone captive-browser and Safari fixes, phone reconnection detection, 2×2 vertical print-sheet composition, photo framing, print approval, and a configuration interface. For detailed history see the `booth20.py` module header.
