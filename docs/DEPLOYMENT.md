# Deployment record

The photo booth was used at a California quinceañera on November 14, 2026. Guests used the capture/download workflow and submitted their own physical print requests. Per the author's firsthand account, printing operated during the event without requiring manual approval for each guest's sheet. The software supports both automated dispatch and optional operator moderation, plus a manual fallback. The actual printer connection configuration used at the event is not available in this repository.

The author recalls bringing approximately 30–40 sheets of photo paper, with none left unused at the end of the event. Paper depletion is evidence of consumption, not an exact, independently verified successful print count. This remains a single field event, not a statistically measured reliability trial; see [event data recovery](EVENT_DATA_RECOVERY.md). No private event photo archive is stored in this repository.
